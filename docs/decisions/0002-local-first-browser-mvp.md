# ADR 0002：Game Lab MVP 采用 Local-first 浏览器实现

- **状态**：Accepted
- **日期**：2026-10-02

## 背景

Game Lab 需要验证“口碑洞察 → 机制假设 → 可玩原型 → 实验结果”的主线。
如果第一版就引入后端、账号、数据库和模型服务，会带来较高成本，并延缓核心假设验证。

## 决策

MVP 采用纯浏览器、Local-first 实现：

- 静态 HTML / CSS / JavaScript；
- 分析逻辑使用本地规则引擎；
- 实验数据存储在 `localStorage`；
- 支持 JSON 导入导出；
- 不依赖后端和外部模型。

## 原因

1. **验证速度优先**
   先验证产品主线是否成立，再投入服务端建设。

2. **部署成本最低**
   静态页面可直接运行，适合给策划、PM 和小团队试用。

3. **数据可控**
   导出 JSON / CSV 后可以进入后续统计流程，不阻塞早期实验。

4. **边界清晰**
   本地规则引擎明确不是生产级 AI，降低过度承诺风险。

## 影响

### 正面影响

- 无需服务器即可跑通完整闭环；
- 便于快速演示和收集反馈；
- 数据结构可以先在浏览器中稳定下来；
- 后续可平移到服务端。

### 负面影响

- 无法多人协作；
- 数据只保存在本地浏览器；
- 无法做真实统计显著性检验；
- 样本量受本地使用限制。

## 结论

第一版 Game Lab MVP 采用 Local-first 浏览器实现。
当需要多人实验、云端回传和统计检验时，再引入服务端与数据库。
