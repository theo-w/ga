# ADR 0001：单独新增 Game Lab 原型页

- **状态**：Accepted
- **日期**：2026-10-02

## 背景

现有 `index.html` 已经承担“竞品口碑分析”职责。  
若直接在其中继续扩展“立项实验室”，会导致：

1. 信息架构混杂；
2. 分析工具和实验平台边界不清；
3. 用户无法判断当前任务是“看报告”还是“做立项实验”；
4. 单文件继续膨胀，不利于后续拆分。

## 决策

新增独立页面 `lab.html`，作为 **AI 原生游戏立项实验室** 的专用原型。

原因：

1. **任务不同**  
   - Game Analyzer 解决“看懂口碑”。
   - Game Lab 解决“验证机制假设”。

2. **用户心智不同**  
   - 前者是诊断报告工具。
   - 后者是立项实验工作台。

3. **演进方向不同**  
   - 前者强调分析、证据和诊断。
   - 后者强调假设、原型、实验和数据回流。

4. **便于后续拆分**  
   - 先以独立页面验证产品主线；
   - 后续再决定是否合并成一个产品内的两个模块。

## 影响

### 正面影响

1. 产品边界更清晰；
2. 可以快速迭代实验流程；
3. 不影响现有 Game Analyzer；
4. 便于单独验证“立项实验室”这条主线。

### 负面影响

1. 两个页面暂时需要分别维护；
2. 用户需要在两个入口之间切换；
3. 视觉风格需要保持一致，否则会像两个产品。

## 结论

先保留两个入口：

- `index.html`：Game Analyzer
- `lab.html`：Game Lab

等 Game Lab 主线跑通后，再评估是否统一为一个产品内的多模块工作台。
