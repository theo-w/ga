# Quickstart: Guided User Workflow

## Validation

1. Open `lab.html`.
2. Confirm the Input view shows the six-step minimal path.
3. Click `载入演示数据`.
4. Click `分析口碑`.
5. Confirm the page remains on `输入洞察`.
6. Confirm the view scrolls to `动机与缺口`.
7. Read the metric interpretation.
8. Click `进入机制假设`.
9. Confirm the Hypothesis view opens.
10. Open `结果回流` and confirm boundary guidance is shown.

## Automated Check

```bash
npm run check
```
