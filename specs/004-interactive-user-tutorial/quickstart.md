# Quickstart: Interactive User Tutorial

## Validation

1. Open `lab.html`.
2. Confirm the interactive tutorial panel appears.
3. On step 1, enter a business objective.
4. Confirm `我已完成思考，下一步` remains disabled until the objective is meaningful.
5. Advance to step 2 and load demo data.
6. Advance to step 3 and run `分析口碑`.
7. Confirm the tutorial detects the completed analysis.
8. Continue through the tutorial steps.
9. Reload the page and confirm the tutorial step persists.
10. Use `跳过教程` and then `重新开始教程`.
11. Complete the final decision step.

## Automated Check

```bash
npm run check
```
