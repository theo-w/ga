Game Lab
AI 原生游戏立项实验室 · Functional MVP

不是“一键生成游戏”，
而是 可跑通的机制验证闭环

输入口碑样本，识别玩家动机与缺口；生成机制假设和实验方案； 在浏览器中游玩最小机制原型，采集行为事件，输出实验结论并沉淀机制知识。 当前版本为 Local-first 功能型 MVP，不依赖后端。

输入：评论样本 输出：机制假设 + 实验结果 存储：浏览器 localStorage
1
口碑输入
真实评论 JSON / 演示数据 / 按行输入
2
动机与缺口识别
本地规则引擎 + 证据链
3
机制假设与实验
可测试命题 + 对照组设计
4
可玩原型与回流
行为事件 + 指标 + 知识沉淀
当前版本验证产品主线，数据保存在本地浏览器。行为实验样本通常很小，结果不能直接用于正式立项决策。
