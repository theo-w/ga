Game Lab
AI 原生游戏立项实验室

不是“一键生成游戏”，
而是 AI 原生的游戏机制验证闭环

Game Lab 的目标是把传统立项会议里的“几个人凭经验组合玩法”， 变成一条可重复的工程化流水线： 从真实玩家口碑中识别动机缺口，生成机制假设，产出最小可玩原型， 通过对照实验验证机制是否成立，并把结果沉淀为可复用的机制知识。

目标用户：产品经理 / 策划 / 立项评审 核心交付：机制假设 + 原型 + 实验结论 当前形态：规则引擎演示原型

机制假设

把口碑缺口转成可验证的设计命题

Step 3
HYP-001

生物不只是战斗伙伴，而是可部署的生产单元

目标玩家
喜欢收集、自动化与轻协作的玩家
机制组合
生物收集 + 岗位部署 + 基地自动化
差异点
收集物从“资产”变成“生产力与情感资产”
先例
幻兽帕鲁 / 星露谷物语 / Valheim
验证方式
10 分钟原型 + A/B 实验
风险：自动化过强可能削弱玩家主动操作参与感。
证据：跨 3 款竞品重复出现“希望生物参与生产”动机。
HYP-002

共同祭坛目标能提升后期协作动机

目标玩家
偏社交、喜欢共同目标的中小队玩家
机制组合
资源贡献 + 阶段解锁 + 共同建造
差异点
把个人自动化成果转化为团队共享目标
先例
Valheim / 帕鲁基地建设
验证方式
有无共同目标两个版本对照
风险：共同目标可能被高活跃玩家代打，弱化普通玩家参与。
证据：后期目标不足在 2 款竞品中重复出现。
HYP-003

生物岗位组合能创造策略表达

目标玩家
喜欢系统优化与构建的玩家
机制组合
岗位角色 + 组合加成 + 产线规划
差异点
让自动化从流水线摆放升级为生物配队策略
先例
自动化工厂 / 生物收集
验证方式
是否主动调整岗位组合与重开
风险：策略过深可能提高理解成本。
证据：自动化策略表达不足的动机强度为 58%。

Step 4

核心循环

捕捉 → 分配 → 生产 → 解锁 → 再捕捉
玩家捕捉具有不同能力的生物，把它们部署到采集、加工、运输等岗位， 生成资源并解锁更高级的生物或设施。 关键不是美术表现，而是确认这个循环是否让玩家产生持续调整和重开动力。

下一版机制方向

结果不是“立项 / 不立项”的二元判断，而是给出下一轮实验方向。

保留

修改

机制知识库

沉淀“机制 → 动机 → 效果 → 边界”

Step 7
生物岗位机制
动机：收集自动化表达
在生存建造类中，把收集物转成生产单元可提升策略表达，但需要控制自动化深度，避免玩家失去主动参与。
共同目标机制
动机：协作成长社交
共同建造目标适合中小队协作，但需要防止高活跃玩家代打，建议加入个人贡献可见性。
岗位组合加成
动机：策略优化重玩
组合加成能提高重开率，但初期只保留 2-3 个可理解变量，避免策略复杂度压过核心乐趣。
